# Nusa Market

Landing page responsif untuk konsep toko produk Asia. Dibuat dengan HTML, CSS, dan JavaScript tanpa dependensi.

## Fitur

- Desain responsif untuk desktop dan perangkat seluler
- Filter kategori produk
- Interaksi keranjang sederhana
- Form newsletter dengan notifikasi
- Navigasi seluler dan markup aksesibel

## Menjalankan secara lokal

Buka `index.html` langsung di browser atau jalankan server statis dari folder proyek.
